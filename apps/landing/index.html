Propuesta

Tu agenda, pasada por el zedazo fino.

Zedazo criba, normaliza, clasifica y deduplica contactos VCF exportados desde ProtonMail, Google Contacts o Apple iCloud. Reglas deterministas, auditoría trazable y procesamiento local: no es un SaaS ni una nube de agendas.

Código en GitHub Crate en crates.io docs.rs

Características

  • Local por defecto

    El cribado corre en tu máquina. Esta ficha no recibe agendas.

  • Determinista

    Mismas reglas, mismo resultado. La auditoría deja constancia de cada decisión.

  • Self-hosted

    CLI para automatizar. GUI y API en loopback, o remoto con HTTPS y token (ADR-0016).

  • Código abierto

    Licencia dual MIT OR Apache-2.0. MSRV Rust 1.80+.

Funcionalidades

Pipeline VCF

  1. Parsear vCard 3.0 y 4.0 (Proton, Google, Apple).
  2. Normalizar nombres, teléfonos y organizaciones.
  3. Clasificar, cribar y deduplicar con reglas TOML.
  4. Escribir VCF limpio y auditoría TSV, CSV o JSON.

CLI

cargo install zedazo
zedazo cribar contactos.vcf -o limpio.vcf -a auditoria.tsv

También audit, stats, export y completions. CardDAV (pull, escritura opt-in, watch) vive en la CLI, no en esta página.

GUI

  • Procesar, ejecuciones, auditar, reglas y ajustes.
  • Paridad funcional con la CLI, salvo el autocompletado de shell.
  • Sin API, la interfaz muestra fixtures sintéticos. Un VCF real sigue exigiendo zedazo-api.

Roadmap

Estado honesto del repositorio. No es una promesa de fecha.

  • Hecho CLI de cribado, GUI y API self-hosted, remoto HTTPS + token, design system OKLCH.
  • Hecho en CLI CardDAV: listar, pull, escritura con confirmación y watch. La GUI no sincroniza libretas.
  • Pendiente humano Tag v0.5.1 y publicación en crates.io. El CNAME de zedazo.alexendros.dev lo crea el operador.
  • v1.0 API de crate estable, benchmarks y corpus de regresión grande.
  • Aplazado OpenTelemetry opt-in. No hay PWA ni notificaciones.
